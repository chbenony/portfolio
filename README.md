# chelseabenony.dev

My personal portfolio site, live at [www.chelseabenony.dev](https://www.chelseabenony.dev).

Built with React, TypeScript, and Vite, and deployed on Vercel.

## Running locally

```sh
cd frontend
npm install
npm run dev
```

Other scripts:

- `npm run build`: type-check and build for production into `frontend/dist`
- `npm run lint`: run ESLint

## Deployment

Vercel deploys `main` to production automatically. Every pull request gets a preview deployment.

## CI

- **Frontend checks**: lint and build on every pull request.
- **Codex review**: automated code review comments on every pull request.
